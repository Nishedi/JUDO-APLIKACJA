\cvitem{2024-present}{Developer}{Klub Judo Przemęt Pohl}{
    Application supporting judo school management implemented at the Przemęt Pohl club (assistant to the national team).
    \begin{itemize}
        \item \textbf{Full-stack web application} built with React frontend and Node.js/Netlify Functions backend, utilizing Supabase for database and authentication.
        \item \textbf{Training management system:} Multi-day activity planning, real-time training schedules with day/week/month views, customizable workout templates with exercises for tactical, motor, and mental training categories.
        \item \textbf{Advanced analytics \& statistics:} Interactive charts and graphs (using Recharts) for tracking athlete performance, weight monitoring, training frequency analysis, and event markers for competitions and training camps.
        \item \textbf{Athlete profiling system:} Comprehensive notes on opponents (fighting style, vulnerabilities, strengths), group-based athlete categorization (senior, junior, youth), video analysis with file management.
        \item \textbf{Communication tools:} Integrated SMS notifications for training sessions, automated password management for athletes, multi-athlete activity broadcasting.
        \item \textbf{Role-based access:} Separate interfaces for coaches (full management) and athletes (view schedules, add personal workouts, access notes), with shared trainer access to athlete groups.
        \item \textbf{Technical highlights:} Activity duplication and editing, drag-and-drop exercise ordering, image annotation for technique analysis, export functionality (PDF generation with jsPDF), responsive design with PrimeReact components.
        \item Successfully deployed and actively used by national team assistant coach and athletes.
    \end{itemize}
}
